## 第十三轮：第一关黄框不显示、镜子反射混入木框背面与屋外草地

### 1. 黄框不显示（真因：门框被抬到天花板里）
- 旧日志证据：`[传送门] 已在墙面上亮起门框：墙面点 (-24.50, 4.89, -100.51)`，
  `[碎片放置] 黑洞已开启：(-24.48, 7.28, -100.51)`。
- `FloorY()` 原来从 `at.y + 1.4` 往下打 6m。这栋楼层高只有 2.8–3m，
  起点 6.29 直接落在上一层楼板**上表面**（6.25），于是量回来的“地面”是**楼上**，
  门框中心 = 6.25 + 1.03 = 7.28，整道门飘进天花板以上 4m，玩家当然看不见。
  交互距离是 3D 距离（3.6m），所以按 E 还能过图 —— 表现就是“能过，但没黄框”。
- 改法：`FloorY` 以玩家 `CapsuleCollider.bounds.min.y`（脚底）为准，
  只在脚边做一次 0.90m 短射线校正；没有玩家时从墙面点**向下**找，绝不从上方起射线。
- 顺带：`FindWallPass` 排除“又窄又厚”的碰撞体（衣帽架/落地灯），
  条件 `max(size.x,size.z) < 1.2 && min(size.x,size.z) > .35`，薄墙/护墙板仍放行。
- 文案：碎片放好后的提示从“墙壁裂开了一个黑洞/黑洞的另一边”改成“墙上亮起了一道门/门的另一边”。

### 2. 镜子里出现棕色木板 + 镜下有草地
- 两个独立原因：
  1. `sm_forgottenmirror` 是 **一个 mesh 两个 submesh**（leg + mirror）。
     渲染反射时只关了 `mirrorRoot.GetComponent<Renderer>()` 和镜面贴片，
     **木框那一层没关** —— 镜后相机就在镜子背后，先撞上木框背面，被拍成那块棕色拱形木板
     （放大截图里它挡在人物小腿前面，形状正好是镜框内沿）。
  2. 原代码把 `nearClipPlane` 沿**视线**推到 `dist - .04`。视线是斜着看镜子的，
     这个平面和镜面不是一个方向，镜后世界（外墙背面被背面剔除 → 直接看到屋外地形/草地）漏进镜面。
- 改法：
  - `CacheMirrorRenderers()`：从选中节点向上爬到 FBX 根，缓存**整棵子树**的 Renderer，
    `mirrorCam.Render()` 前后成对关闭/恢复（记录 enabled 原状）。
    同时不再在兜底分支把 `mirrorRoot` 清空 —— 隐藏要靠它。
  - 改用 `Camera.CalculateObliqueMatrix`：把近裁剪面**钉死在镜面所在平面**
    （`mirrorCenter - N*.02`，往镜后让 2cm 保住镜脚那点地板），镜面之后的一切整片切掉。
  - 符号不靠人肉推（Unity 反 Z，写反会把镜子切空）：`ResolveClipSign()` 用
    “镜前 25cm 的一个小测试盒”做探针，`GeometryUtility.TestPlanesAABB` 判定哪一侧被保留，
    只算一次并缓存 `clipSign`；每次重算前都要 `ResetProjectionMatrix()`，不能在上一帧斜切上再切。
- 注意：`CameraSpacePlane` 的 `sideSign` 是 float，`clipSign` 是 int，隐式转换 OK。

### 关键教训
- 室内做“从上方往下量地面”必错：层高小于 3m 时起点会插进上一层楼板。
  一切高度基准优先用玩家胶囊底。
- 镜子/水面这类平面反射，**必须**用斜投影裁剪；沿视线推 near 平面在斜视角下必然漏景。
- FBX 同名根 + 子网格的结构：关渲染器要关整棵子树，只关根没用。

## 第十三轮：Level 2 换黄昏天空盒 + 整体压暗

用户给了 PS 里打开的 8192×4096 黄昏天空图（只有截图，原文件找不到），要求
“给 Level2 加天空盒，整个场景变暗，但不至于太暗，能看到灯的位置”。

### 天空贴图怎么来的
`C:/Users/zhaop/.workbuddy/clipboard-images/clipboard-2026-11-24T16-39-37-431Z-c2de0103.jpg`
（1920×968 的 PS 截图）→ 裁出画布 → 修掉自由变换框的蓝色对角线和白点手柄 → 重映射。

- 画布真实范围 **x 197–1273、y 97–630**（1076×533，比例 2.019，说明原图就是 2:1）。
- 截图里有 PS 自由变换框：两条**贯穿全图**的 45° 亮蓝线（RGB≈35,61,180，b-g≈120）+ 顶部中间白点。
  裁切去不掉，必须 inpaint。
- 关键坑：**先用高斯模糊再填充会把线条本身的蓝扩散成一条带状痕迹**。
  正确做法是拿 `MedianFilter(13)` 的结果当填充源（中值能整段吃掉 3px 细线，又保住云和渐变）。
- 地平线对齐：照片地平线在 0.745，重映射到 0.5（上半压、下半拉）。
- 这张图**不是真 360° 全景**，当 lat-long 用会让地平线在透视下弯成拱形。
  最终方案：只保留“天顶到约 45° 仰角”那段（无地平线），往下用 `alpha` 从 .13 到 .56
  平滑渐入雾色，跨度 63°，看不到任何弧线。正好对上开场“屋外的白雾是尚未到来的未来”。
- 成品：`Assets/Resources/Level2Sky/sky_dusk.jpg`（4096×2048，293KB）。

### 代码
- 新增 `Assets/Resources/Shaders/SkyboxEquirect.shader`（`House/SkyboxEquirect`）：
  自己按方向算 UV，不依赖内置 `Skybox/Panoramic` 的贴图导入设置。
  `uv.y = acos(d.y)/π`（天顶 0、地平线 .5），`uv.x = atan2(d.z,d.x)/2π+.5`。
- 新增 `Assets/Scripts/Level2/Level2Sky.cs`：设 skybox 材质 + 三色环境光 + reflectionIntensity。
  `Resources.Load<Shader>("Shaders/SkyboxEquirect")`（不能用 Shader.Find，打包会丢）。
- `Level2Director.ApplyMood()`：删掉原来那三行环境光，末尾改调 `Level2Sky.Apply()`；
  点光保留比例 .55 → **.68**（环境暗了之后灯是唯一方向感），射灯 .34 → .30，
  Directional `.16/.22` → **`.08/.10`** 且颜色 (.50,.58,.76)。
- `Level2Director.ApplyFog()`：相机 `clearFlags` 由 SolidColor 改 **Skybox**。

### 两个必须记住的冲突点
1. **`ApplyFog()` 在 Awake 里是 `ApplyMood()` 之后调用的**，它原来把相机设成
   SolidColor 亮灰 (.80,.83,.86) —— 天空盒会被整块盖住。这是“加了天空盒却看不到”的头号原因。
2. **`FutureFog.Start()` 不看场景名**，无条件设雾 + 相机 SolidColor。
   它挂在玩家预制体上，进 Level 2 也会跑。已加 `if (SceneManager.GetActiveScene().name != "Level 1") return;`。
   （第一关行为完全不变。）

### 故意没做的事
- **不加雾**：`Level2Director.Update()` 每帧 `RenderSettings.fog=false`，
  而且这栋楼一楼走廊十几米，以相机为圆心的距离雾会糊成一堵白墙（之前踩过）。
  暗只靠环境光 + 天空盒给。
- **不改场景文件**：`Assets/Level 2.unity` 的 mtime 仍是 23:56（用户自己删相框那次），
  本轮所有效果都在运行时装配。代价是编辑器里打开场景看不到变化，要 Play 才生效。

### 数值（想调就改这几个）
- `SkyExposure = .90`（1.2 接近傍晚，0.6 更暗）
- 环境光 (.048,.054,.068) / (.026,.030,.038) / (.011,.012,.015)，约原来四成半
- 太黑：三组各 ×1.4；不够暗：×0.7


## 信纸（小木盒里的信）：改成“钢笔手写 + 一个字一个字写出来”

### 内容
`Level2Mirror.OnBoxOpened()` 里的 `Ui?.Letter(...)` 换成「小时候的我 → 长大以后的我」，
抬头 `写给长大以后的我`，落款 `—— 小时候的我`，呼应序幕那句「写给长大以后的我。十年之后，我才敢拆开它。」
正文 189 字 / 21 行，分 5 段（打招呼 / 我字写得歪 / 房间现在的样子 / 妈妈说要一直期待 / 你走累了就回来）。

### 字体
`Assets/Resources/Fonts/LongCang.ttf`（龙藏，Google Fonts，OFL 1.1，5.1MB，7016 个码位，
`lineHeight/em = 1.0`）+ 同目录 `OFL-LongCang.txt`。
`Level2Ui.Awake()` 里 `Resources.Load<Font>("Fonts/LongCang")`，取不到就退回系统字体（不会白屏没字）。
**只有信纸用这个字体**（`PenStyle`），提示框/黑幕仍是雅黑。

### 逐字书写
- `Level2Ui` 新增 `letterChars / letterTimer`，`Update()` 里按 `LetterCharDelay .045s` 推进；
  换行停 `.22s`、句号/破折号停 `.14s`、逗号顿 `.11s`（≈逗号是 2 倍字间隔）。整封约 12 秒。
- `AllTyped` 现在同时管 Ending 和 Letter；字没写完按空格 = `FinishTyping()` 一次补全（不是跳过整页），再按一次才合上。
- 提示文字三态：`空格跳过书写` / `空格合上` / 回看时 `空格返回`。
- 字号自适应：`CalcHeight` 真量，装不下就一号一号往下收，结果缓存在 `letterFitSize`
  （OnGUI 一帧进来好几次，不能每帧跑几十遍 CalcHeight）。

### 书写音效
项目里没有笔尖采样，`GameAudio.BuildPenScratch()` 运行时合成：白噪声 → 两级低通 → 快起慢收包络
→ 叠 63Hz 颗粒 → 0.07s。`PlayPen()` 每字一响，pitch `.85~1.18`、音量 `.45~.75` 随机，避免机械节拍。
（写真实采样的话，替换 `penClip` 即可，调用点不用动。）
