  `!StoryProgress.IsShowingPage` 守卫，避免点按钮时被抢回去。

## 修书房/卧室书桌两侧灯开关只亮"别人家的灯"的 bug
- 场景 `Assets/Level 1.unity`（56MB，纯文本 YAML，可直接文本改）。
- 书桌在卧室（PP_Bedroom 那间，桌面上有报纸/书/信封碎片① 等，坐标约 x -19.4、y 4.0、z -93），
  两侧墙上的两个开关是 `SM_Swith_A7`（z -91.85）和 `SM_Swith_A8`（z -94.36），都在 x=-19.10 同一面墙、y=3.96。
- 该房间的天花板主灯是 **SM_Lamp_D**（RoomLamp 组件 fileID `1613920891`，Light `2135431777`，point 光 range6 I2.3，y 5.59，realtime）。
- 原接线：A7 → SM_Lamp_C2 + SM_Lamp_D + SM_Lamp_C3；A8 → SM_Lamp_D2 + SM_Lamp_E5（D2/E5 在隔壁房间）。
  所以按一侧时亮的其实是隔壁房灯，本房间主灯不亮。
- 改法：把两个 HouseLightSwitch（组件 fileID `1389949927` / `1838783086`）的 `lamps` 数组都改成只有 `{fileID: 1613920891}`，
  即两侧开关变成同一盏吊灯的双控，不再带动其它灯。
- 场景里灯光基本都是 `m_Lightmapping: 4`（Realtime），所以运行时开灯有效；RoomLamp.Apply 里 `isOn && isActiveAndEnabled` 要注意灯具对象别禁用。

## 关卡一顺序重做：中间抽屉上锁 + 碎片一阅读页 + 房间门闸门
- **抽屉定位关键结论**：书桌三个抽屉的名字只存在于 FBX 的**网格名**（`Draw 1_low` / `2_low` / `3_low`），
  场景里 GameObject 不叫这个名字（`m_Name` 里搜不到 "Draw"）。所以按物体名 `Draw 1_low` 找是找不到的，
  只能用 `MeshFilter.sharedMesh.name` 匹配（和 `DrawerSetup.IsPanelMesh` 同一条规则）。
